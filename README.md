# Red-Queen

[English](#english) · [Español](#español)

## English

RED QUEEN is a recently started final-year Computer Engineering project, developed by a team at Universidad Complutense de Madrid. Its proposed direction is an adaptive cybersecurity training environment combining practical labs, a learner model and a conversational teaching assistant.

Current code experiments focus on a **Networks and Security assistant** using Python, Streamlit, LangChain, Chroma and the OpenAI API. The [prototype](C%C3%B3digo/Agente-Profesor/ChatBot_Beta) contains a chat interface, PDF retrieval and separate theory and lab views. These are initial experiments; the integrated platform and its educational effectiveness have not been demonstrated or evaluated.

Learner modelling with Bayesian Knowledge Tracing and adaptation are research objectives in the [project plan](Planteamiento%20y%20planificacio%CC%81n%20de%20RED%20QUEEN.docx). They should be read as planned work. Dependency setup and reproducible execution instructions remain to be documented.

## Español

RED QUEEN es un TFG de Ingeniería Informática recién iniciado, desarrollado en equipo en la Universidad Complutense de Madrid. La propuesta es un entorno de formación adaptativa en ciberseguridad que combine laboratorios prácticos, un modelo del alumno y un profesor conversacional.

Los experimentos actuales se centran en un **asistente de Redes y Seguridad** con Python, Streamlit, LangChain, Chroma y la API de OpenAI. El [prototipo](C%C3%B3digo/Agente-Profesor/ChatBot_Beta) contiene una interfaz de chat, recuperación sobre PDF y vistas diferenciadas de teoría y prácticas. Son experimentos iniciales; la plataforma integrada y su eficacia educativa aún no se han demostrado ni evaluado.

El modelado del alumno mediante Bayesian Knowledge Tracing y la adaptación son objetivos de investigación del [plan](Planteamiento%20y%20planificacio%CC%81n%20de%20RED%20QUEEN.docx). Quedan por documentar las dependencias y la ejecución reproducible.
